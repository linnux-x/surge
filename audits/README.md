# 审计记录

本目录保存**时点快照**：每份文档只反映其审计日期当时的仓库状态，不随代码更新，也不是当前状态的说明。

- 命名：`<主题>-YYYY-MM-DD.md`
- 每份文档开头必须写明审计对象的 commit 与日期
- 结论过期后不要就地改写正文，而是在开头补一段复核状态表，保留原始判断以便追溯

仓库的**常青文档**在根目录，不要放进这里：`README.md`（公开入口）、`SOURCE_OF_TRUTH.md`（公私边界与下游契约）、`CONTRIBUTING.md`（贡献流程）。

把两类文档分开正是本目录存在的原因：`full-repo-audit-2026-07-03.md` 此前放在仓库根目录，与常青文档混在一起，直到 280 个提交之后才被发现其中多数结论已经失效。
